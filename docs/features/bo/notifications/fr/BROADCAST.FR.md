## Où trouver cette page

Menu de gauche → groupe **Communauté** → **Diffusion**. Adresse : `/diffusion`.

## À quoi sert cette page

Écrire une annonce et l'envoyer d'un coup à tous les membres, ou à ceux d'une ville, dans les trois langues
(incident, nouveauté…).

## Qui peut l'utiliser

Le droit « diffusion », accordé dans le formulaire d'un poste (page **Droits**). Il est distinct du droit
sur les notifications, car écrire à toute la communauté est une décision réservée à quelques personnes ; le
serveur le contrôle aussi.

## Ce que l'on voit à l'écran

- Le choix des **destinataires** : tous les membres, ou les membres d'une ville.
- Un **titre** et un **message**, avec un onglet par langue.
- Le nombre de destinataires estimé, avec un bouton **Vérifier les destinataires**, et un **aperçu** de
  l'annonce.
- L'historique des **dernières annonces** (audience, expéditeur).

## Actions possibles

- **Vérifier les destinataires**, puis **Envoyer l'annonce**. Une fenêtre de confirmation rappelle le nombre
  de membres touchés et exige de cocher « J'ai relu le message et les destinataires » ; l'envoi ne peut
  ensuite ni être annulé ni modifié.

## Cas d'utilisation typiques

1. **Prévenir d'une maintenance** tous les membres.
2. **Informer une ville** d'une nouveauté locale.

## Points d'attention / limites actuelles

- Dans l'état actuel du menu, l'entrée **Diffusion** n'apparaît pour aucun poste : la page n'est atteignable
  que par son adresse. Un défaut de configuration du menu est à corriger.
- Les membres du portfolio sont peu nombreux ; l'audience « ville » repose sur l'adresse saisie dans un
  profil de covoiturage.
