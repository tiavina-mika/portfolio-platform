## Où trouver cette page

Menu de gauche → groupe **Finance** → **Finance**. Adresse : `/finance`.

## À quoi sert cette page

Comparer le volume brut payé et le revenu net retenu par la plateforme, repérer les paiements bloqués en
attente et suivre les soldes des conducteurs. Cette rubrique vient d'une application de covoiturage payant.

## Qui peut l'utiliser

Le droit « finance », accordé dans le formulaire d'un poste (page **Droits**). Il est distinct du droit sur
les statistiques, pour qu'un poste puisse voir l'activité sans voir le revenu réel. Les comptes Owner et
Super Admin ont tous les droits.

## Ce que l'on voit à l'écran

- Une vue d'ensemble : volume brut, revenu net, comparaison par période.
- Une liste des **paiements en attente en retard**, avec une action pour relancer la vérification auprès de
  l'opérateur.
- Un suivi des **portefeuilles conducteurs** (pénalités en attente, comptes suspendus, historique des
  versements).

## Points d'attention / limites actuelles

- Le serveur du portfolio ne fournit pas les données de cette page (ni la vue d'ensemble, ni les paiements
  en retard, ni les portefeuilles) : elle affiche une erreur ou reste vide.
- Il n'y a ni paiement ni conducteur dans un portfolio ; la page est sans objet tant que ce n'est pas le cas.
