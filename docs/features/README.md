## Pour qui

Ces pages décrivent, sans jargon technique, ce que fait chaque écran. Elles sont écrites en français uniquement et mises à jour dès qu'un comportement visible change dans `apps/bo` ou `apps/web`.

## Back-office

Le [back-office](bo/README.md) est le panneau d'administration du portfolio : projets, articles, pages, catégories, messages de contact, utilisateurs et rôles.

## Site public

Le [site public](web/README.md) présente les projets et les articles, et permet de contacter le propriétaire ou de s'abonner à la newsletter.

## Règles

- Un dossier par application (`bo`, `web`), une page par écran ou par ensemble d'écrans cohérent.
- Pas de nom de fichier, de composant ni de fonction dans ces pages : elles sont lues par des personnes non techniques.
