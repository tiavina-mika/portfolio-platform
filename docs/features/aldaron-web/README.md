- [About](about/fr/ABOUT.FR.md): who Aldaron is, how it works, who it works for.
- [Contact](contact/fr/CONTACT.FR.md): the quote request form.
- [Legal notice](legal/fr/LEGAL.FR.md) and [Privacy](legal/fr/PRIVACY.FR.md): the legal texts, linked from the footer.
