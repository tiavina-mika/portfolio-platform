Accepting a quote can now join one proof file (the signed quote or the client's e-mail, as a PDF or an image, 5 MB at most), stored with the other back-office files; the quote list then offers an "Acceptance proof" link under the status of that quote. The server takes a proof only with the acceptance itself, and only a file uploaded to the platform's own proofs folder. No migration: older accepted quotes simply have no proof.
