Étiquette de statut (Actif, Invité, Suspendu) ou de catégorie ; texte de 1 à 2 mots.

```jsx
<Badge variant="success" dot>Actif</Badge>
<Badge variant="warning" dot>Invitation envoyée</Badge>
<Badge variant="brand" mono>Inclus dans le socle</Badge>
<Badge variant="outline">Éditeur</Badge>
```

- Statuts : toujours `dot` + couleur sémantique ; le texte porte le sens, la couleur le renforce.
